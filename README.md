# Remot Canggih

Aplikasi remot TV Android gratis, tanpa iklan, tanpa login.

- Remot via WiFi untuk Android TV / Google TV (Coocaa, Sharp, Polytron, TCL, Xiaomi, dll)
- Tab Remot, Touchpad, Aplikasi + mode ketik dan input suara
- Bahasa Indonesia

Download: https://baramarket.my.id/remot/download

## Build

APK dibuat otomatis oleh GitHub Actions setiap ada push ke `main`, lalu diterbitkan di
[Releases](../../releases/latest). Link download selalu ke versi terbaru:

```
https://github.com/baramarketID/remot-canggih/releases/latest/download/RemotCanggih.apk
```

Secret yang dibutuhkan (Settings → Secrets and variables → Actions):
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
